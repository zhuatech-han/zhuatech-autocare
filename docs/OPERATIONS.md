# 汽修操作手册

知华科技 · 上海如静知华信息科技有限公司 · https://www.zhuatech.cn/ · 微信 zhuatech / zhuatech2。

1. 管理员创建员工账号，分配服务顾问、技师、配件员、质检员或收银角色与门店部门。使用独立强密码。账号禁用、改密或撤权立即影响后续请求；最后一个启用的全范围管理员受保护。
2. 顾问维护客户、车辆、工时及配件。车辆编号可用车牌，VIN 可选。基本单位和部门不要用来换算历史数据；已引用档案优先停用而非删除。
3. 配件员在“配件库存”收货，登记实际量、单位成本及外部凭证；库存开始为零。盘点前读最新账面，差额按移动平均减值或新增单位成本入账。后台没有采购应付功能。
4. 顾问接车，记录里程、诉求、外观及随车物品。已有在修工单须先处理；重复车辆和倒退里程会拒绝。报价前可修改接车说明及向前修正里程。
5. 创建报价选择工时/配件及商定数量单价。草稿可编辑删除；“提交报价”冻结内容。实际取得车主同意后填写确认方式、外部记录编号，再记录接受；拒绝也保存说明。此记录不是电子签名，应单独保存授权原件。
6. 顾问指派同门店启用技师。技师进入自己的工单开工。配件员只能从已经接受的报价领料；库存不足先补充收货。追加维修建立新报价，车主另行确认后才能执行。
7. 未用配件在维修项完成前，选择原领料流水退回；累计不能超过原领料，成本按原领料恢复。配件完成时净领用即实际耗用；少于授权量可完成，填写原因并核对实物。未领用部分不收费。工时按授权数量计费，不是自动计时。
8. 技师逐项填写完成说明。所有接受项目都完成、无草稿或待确认报价时送质检。质检员必须实际检查后记录通过/退回。退回重检可以补充新项目，已有完成项保持冻结；不应为了纠正错误删除流水。
9. 质检通过后收银按已完成项目结算；如需优惠登记金额。核对实际收到现金或转账的凭证后登记收款，允许分次，禁止超收。金额录错选择原收款“冲销”，填写原因及凭据，原记录不删除。该操作不调用银行退款。
10. 款项结清后填写车主领取凭据并交车。交车后工单冻结；本版没有交车后退款/返修关联。车辆页查看自己权限范围的历史；经营报表仅统计已质检工单，按接车日期过滤。

## 打印、导入和导出

工单中每份报价可以打印，页面显示当前授权状态及确认记录。结算打印仅统计接受报价的已完成工时与实际配件，草稿打印不可当成交车发票。打印纸张选择 A4。业务打印、CSV 和数据载荷不插入商业推广。

配件页“导入”给出 JSON 模板，替换示例编码和内容；每批1–500项，各项部门须在账号范围内，数量/价格须合法；其中一条失败整个批次回滚。不能通过导入直接填库存，需要真实收货凭证。CSV 报表对电子表格公式前缀转义。

## 故障与纠错

超时或重复点击先刷新台账，不重复录收款。尚可执行的同一动作可用相同请求标识重试；内容不同会拒绝。状态冲突不能通过新建标识绕过。盘点过期须刷新账面数量/价值后重新实盘。

没有技术支持承诺或第三方支付接入；商业实施、授权及深度定制通过知华科技咨询。
